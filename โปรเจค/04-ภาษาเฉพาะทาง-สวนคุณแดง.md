# ภาษาเฉพาะทาง

**1. ชื่อผลงาน**
การพัฒนาเว็บแอปพลิเคชันระบบจองต้นไม้ ร้านสวนคุณแดง

**2. ภาษาที่ใช้**
TypeScript, JavaScript, CSS, HTML

**3. คำศัพท์ภาษาเฉพาะทาง**

| คำศัพท์ | ภาษาอังกฤษ | ความหมายในโปรเจค |
| :--- | :--- | :--- |
| เว็บแอปพลิเคชัน | Web Application | ระบบซอฟต์แวร์ที่ทำงานผ่านเบราว์เซอร์อินเทอร์เน็ต สร้างด้วย Next.js 14 |
| คอมโพเนนต์ | Component | ชิ้นส่วนย่อยของหน้าต่างแสดงผลที่สามารถนำกลับมาใช้ซ้ำได้ เช่น แถบเมนู ส่วนท้าย ปุ่ม การ์ดแสดงสินค้า |
| เอพีไอ | API (Application Programming Interface) | ชุดคำสั่งสำหรับรับและส่งข้อมูลระหว่างฝั่งผู้ใช้งานกับฝั่งเซิร์ฟเวอร์ |
| ฐานข้อมูล | Database (PostgreSQL + Prisma ORM) | ระบบจัดเก็บข้อมูลต้นไม้ สมาชิก และรายการจอง โดยมีเครื่องมือช่วยจัดการข้อมูล |
| การจอง | Booking | ข้อมูลการสั่งจองต้นไม้ล่วงหน้า มีสถานะ เช่น รอชำระเงิน ยืนยันแล้ว เสร็จสิ้น และยกเลิก |
| มัดจำ | Deposit | จำนวนเงินที่ต้องชำระล่วงหน้าเพื่อยืนยันสิทธิ์ในการจองต้นไม้ |
| สต็อก | Stock | จำนวนต้นไม้คงเหลือในระบบสำหรับเปิดให้สั่งจอง |
| โปรโมชั่น | Promotion | ต้นไม้ที่มีการลดราคาพิเศษตามช่วงเวลาที่กำหนด |
| แอดมิน | Admin | บทบาทผู้ดูแลระบบที่มีสิทธิ์จัดการสินค้า ตรวจสอบรายงาน และอนุมัติการจอง |
| สลิป | Payment Slip | รูปภาพหลักฐานการชำระเงินค่ามัดจำที่ลูกค้าส่งเข้าระบบเพื่อขอยืนยันการจอง |
| ตัวแปรสไตล์ | CSS Variables | ตัวแปรกำหนดสี ขนาด หรือคุณสมบัติต่างๆ ที่ใช้ร่วมกันทั่วทั้งระบบ |
| กลาสมอร์ฟิซึม | Glassmorphism | รูปแบบการดีไซน์ส่วนติดต่อผู้ใช้งานให้มีลักษณะคล้ายกระจกฝ้า มีความโปร่งใสและเบลอพื้นหลัง |
| เลย์เอาต์ | Layout | โครงสร้างหลักในการจัดวางเนื้อหาบนหน้าเว็บ |
| รูทเลย์เอาต์ | Root Layout | โครงสร้างพื้นฐานหลักของระบบที่ควบคุมการแสดงผลของหน้าเว็บทุกหน้า |
| อินไลน์เอดิต | Inline Edit | ระบบที่ช่วยให้ผู้ดูแลระบบสามารถแก้ไขข้อความหรือปรับเปลี่ยนสีบนหน้าเว็บได้ทันที |
| ฟอนต์ Prompt | Prompt Font | รูปแบบตัวอักษรภาษาไทยหลักที่นำมาใช้แสดงผลในเว็บแอปพลิเคชันเพื่อความสวยงามและอ่านง่าย |

**4. การกำหนดสีและรูปแบบหลักของระบบ**
การกำหนดสไตล์ร่วมผ่าน globals.css ช่วยควบคุมธีมสีและการแสดงผลที่สอดคล้องกันตลอดทั้งเว็บแอปพลิเคชัน มีรายละเอียดดังนี้:
*   **ชุดสีหลักประจำร้าน (Nature Palette):**
    *   **สีหลัก (Primary Color):** ใช้รหัสสี `#d9381e` (สีแดงส้ม) เป็นสีหลักสำหรับปุ่มสั่งงานที่สำคัญที่สุด เช่น ปุ่มจองต้นไม้ หรือปุ่มยืนยัน
    *   **สีรอง (Secondary Color):** ใช้รหัสสี `#2c5530` (สีเขียวเข้ม) สำหรับข้อความหัวข้อ โลโก้ และส่วนเน้นความสำคัญ
    *   **สีพื้นหลัง (Background Color):** ใช้รหัสสี `#fdfaf6` (สีครีมอ่อน) เพื่อสร้างบรรยากาศธรรมชาติ สบายตา และมีสไตล์พรีเมียม
    *   **สีข้อความหลัก (Foreground Color):** ใช้รหัสสี `#1c261e` (สีดำอมเขียว) ช่วยให้อ่านข้อความได้ชัดเจนและไม่ล้าสายตา
    *   **สีเน้น (Accent Color):** ใช้รหัสสี `#f4eae6` (สีเบจธรรมชาติ) เป็นสีพื้นหลังสำหรับกล่องข้อมูลเด่น
*   **ชุดสีส่วนประกอบเพิ่มเติม:**
    *   **พื้นหลังส่วนท้ายเว็บ (Footer BG):** ใช้รหัสสี `#2d3e2d` (สีเขียวเข้มหม่น)
    *   **แถบล่างสุดของเว็บ (Footer Bar):** ใช้รหัสสี `#7fb069` (สีเขียวอ่อนใบไม้)
    *   **ตัวเลขแจ้งเตือน (Badge Error):** ใช้รหัสสี `#ef4444` (สีแดงเตือน) สำหรับจำนวนสินค้าในตะกร้า
*   **เอฟเฟกต์การแสดงผล:**
    *   **สไตล์กระจกฝ้า (Glassmorphism):** นำไปใช้กับแถบนำทางด้านบน (Navbar) เพื่อความลอยตัว สวยงาม และสามารถมองเห็นเนื้อหาด้านหลังจางๆ ได้ขณะเลื่อนหน้าจอ
    *   **การ์ดลอยเมื่อชี้เมาส์ (Hover Card):** การ์ดแสดงผลต้นไม้จะขยับตัวลอยขึ้นเล็กน้อยและมีเงาเข้มขึ้นเมื่อผู้ใช้งานชี้เมาส์ เพื่อชวนให้คลิกและตอบสนองการใช้งานที่ดี
    *   **แอนิเมชันเปิดตัว (Fade-In Animation):** ข้อความหรือองค์ประกอบสำคัญจะค่อยๆ ปรากฏและขยับขึ้นอย่างนุ่มนวลเมื่อเลื่อนหน้าจอมาถึง

**5. โครงสร้างหลักของเว็บแอปพลิเคชัน**
โครงสร้างการทำงานและดีไซน์ส่วนหลักของหน้าเว็บประกอบด้วยส่วนสำคัญ 5 ส่วน:
*   **โครงสร้างหลักระบบ (Root Layout):** ทำหน้าที่เป็นแม่แบบหลัก ครอบคลุมการทำงานของทุกหน้าเว็บ ควบคุมการโหลดแบบอักษรไทย (ฟอนต์ Prompt) และกำหนดรายละเอียดสำคัญสำหรับการค้นหาบนกูเกิล (SEO Metadata) เช่น ชื่อและรายละเอียดของร้าน
*   **แถบนำทางหลัก (Navbar):** แบ่งการทำงานออกเป็น 3 แถบย่อย ได้แก่ แถบข้อความประชาสัมพันธ์ด้านบนสุด แถบกลางสำหรับแสดงโลโก้ร้าน ช่องค้นหาต้นไม้ และไอคอนตะกร้าสินค้าที่มีตัวเลขแจ้งเตือนจำนวน และแถบล่างสุดสำหรับเมนูลิงก์ไปยังหน้าต่างๆ ของเว็บ รวมถึงหน้าผู้ดูแลระบบสำหรับจัดการหลังบ้าน ทั้งนี้ แถบนำทางได้รับการออกแบบให้รองรับการเปลี่ยนรูปแบบเป็นแถบนำทางที่ด้านล่างสุดเมื่อเปิดด้วยมือถือ เพื่อความสะดวกในการใช้นิ้วกดสั่งงาน
*   **การดึงข้อมูลและแสดงผลหน้าหลัก (Homepage):** ทำการดึงข้อมูลสดใหม่มาแสดงผลทุกครั้งเมื่อมีผู้เข้าชม เช่น รายการต้นไม้ขายดีประจำสัปดาห์ที่คำนวณจากคำสั่งซื้อที่เสร็จสมบูรณ์ และรายการต้นไม้โปรโมชั่นที่ยังไม่หมดเวลาส่วนลด หากเกิดเหตุขัดข้องในการเชื่อมต่อระบบจะมีข้อมูลตัวอย่างแสดงขึ้นมาทดแทนโดยอัตโนมัติ เพื่อป้องกันหน้าจอว่างเปล่า
*   **ส่วนท้ายของหน้าเว็บ (Footer):** เป็นกล่องสีเขียวเข้มท้ายเว็บไซต์สำหรับบอกข้อมูลการติดต่อ ช่องทางการชำระเงินที่สำคัญ เช่น คิวอาร์โค้ดพร้อมเพย์ บัญชีโอนเงินของทางร้าน ลิงก์แผนที่ ข้อมูลลิขสิทธิ์ และลิงก์หน้าข้อมูลช่วยเหลือของร้านค้า
*   **การแสดงผลตอบสนองขนาดหน้าจอ (Responsive Grid Layout):** นำระบบจัดการพื้นที่ตารางมาช่วยจัดสัดส่วนการแสดงผล เช่น แสดงเนื้อหาแบบ 2 คอลัมน์แยกซ้ายขวาบนหน้าจอคอมพิวเตอร์ และปรับหน้าจอเป็นคอลัมน์เดี่ยวแนวตั้งอัตโนมัติบนมือถือ พร้อมทั้งซ่อนส่วนที่ไม่จำเป็นบนหน้าจอขนาดเล็กเพื่อให้อ่านข้อมูลได้สะดวกที่สุด

**6. ส่วนประกอบย่อยที่สำคัญของแอปพลิเคชัน**
*   **ปุ่มสั่งงานระบบ (Button Component):** ออกแบบปุ่มกดให้มีความโค้งมนสวยงามตามมาตรฐาน 12 พิกเซล รองรับรูปแบบการใช้งาน 4 ประเภท ได้แก่ ปุ่มสำหรับทำงานหลัก (สีแดงส้ม) ปุ่มทำงานรอง (สีเขียวเข้ม) ปุ่มกรอบเส้นขอบ (ไม่มีสีพื้นหลัง) และปุ่มโปร่งใส ซึ่งแต่ละแบบสามารถกำหนดขนาดได้ 3 ระดับ (เล็ก กลาง ใหญ่) ตามความสำคัญของตแหน่งที่แสดงบนหน้าเว็บ

**7. รายการคอมโพเนนต์ทั้งหมดในระบบ**

| ชื่อ Component | หน้าที่การทำงาน |
| :--- | :--- |
| Navbar | แถบเมนูนำทางหลักส่วนบนของเว็บไซต์ และแถบเมนูสำหรับกดด้านล่างเมื่อแสดงบนมือถือ |
| Footer | ส่วนแสดงข้อมูลติดต่อ ช่องทางจ่ายเงิน และแผนที่บริเวณท้ายเว็บไซต์ |
| Button | ปุ่มกดสำหรับรับคำสั่งต่างๆ เช่น ยืนยัน จอง หรือย้อนกลับ |
| Card | กล่องสี่เหลี่ยมโค้งมนสำหรับจัดแสดงภาพและรายละเอียดเบื้องต้นของต้นไม้แต่ละต้น |
| Badge | ป้ายสัญลักษณ์ขนาดเล็กเพื่อระบุสถานะ เช่น สินค้ามาใหม่ หรือสัญลักษณ์ป้ายลดราคา |
| ImageSlider | แผงเลื่อนภาพและรายละเอียดต้นไม้ขายดีเพื่อให้สามารถกดเลื่อนดูซ้ายขวาได้ |
| ImageGallery | อัลบั้มรูปภาพสินค้าในหน้ารายละเอียดต้นไม้เพื่อให้ลูกค้าเปิดภาพดูหลายมุมมอง |
| PaymentModal | หน้าต่างป๊อปอัปให้ลูกค้าตรวจสอบยอดเงินมัดจำและแนบภาพใบเสร็จเพื่อชำระเงิน |
| FavoriteButton | ปุ่มรูปหัวใจเพื่อให้ลูกค้ากดบันทึกต้นไม้ที่สนใจไว้ในรายการโปรดส่วนตัว |
| ScrollAnimation | ระบบควบคุมการแสดงผลให้เนื้อหาค่อยๆ ปรากฏขึ้นเมื่อผู้ใช้งานเลื่อนหน้าจอมาถึง |
| ParallaxSection | ระบบภาพเคลื่อนไหวพื้นหลังแบบเหลื่อมล้ำระดับความเร็วเพื่อเพิ่มมิติความลึกในหน้าแรก |
| InlineEdit | เครื่องมือพิเศษสำหรับผู้ดูแลระบบให้สามารถคลิกแก้ไขคำและธีมสีบนหน้าเว็บได้ทันที |
| ThaiDatePicker | กล่องเลือกวันที่สำหรับทำรายการจองซึ่งแสดงปีปฏิทินเป็นพุทธศักราช (พ.ศ.) |
| ReviewList | ส่วนแสดงรายการความคิดเห็นและระดับคะแนนดาวที่ลูกค้าเคยเขียนรีวิวให้ต้นไม้ |
| ProductDetail | ส่วนแสดงรายละเอียด ข้อมูลสายพันธุ์ วิธีดูแล และปุ่มทำรายการจองของต้นไม้ |
| AdvancedFilters | ตัวเลือกช่วยกรอง ค้นหา และคัดแยกประเภทต้นไม้ตามราคา ความสูง หรือประเภท |
